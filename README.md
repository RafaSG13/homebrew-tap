# homebrew-tap

Homebrew formulae by RafaSG13.

```bash
brew tap rafasg13/tap
brew install pandora   # Pandora, a terminal vault for secrets
brew install minimal   # minimal (mnml-agent), a terminal coding-agent harness
```

`Formula/pandora.rb` is written by Pandora's GoReleaser on each release; `Formula/minimal.rb` by `scripts/update_brew_formula.py` of [Minimal](https://github.com/RafaSG13/Minimal)'s release workflow.
